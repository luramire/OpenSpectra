OpenSpectra provides the GUI software and the Arduino code to be used with Hamamatsu C12880MA mini-spectrometer chip.

Python packages:
numpy==2.4.4
pyqtgraph==0.14.0
pyserial==3.5
PySide6==6.11.0

Arduino Version:
2.3.8
Board: Arduino Pro Micro 5V (programmed as Arduino Leonardo)

If you need the Windows execucateble, please download it from:
https://sourceforge.net/projects/openspectra/
